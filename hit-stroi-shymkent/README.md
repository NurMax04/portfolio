# HIT STROI SHYMKENT

Одностраничный сайт-визитка с каталогом мебели на заказ. Интерфейс переключается между казахским и русским языками; карточки каталога можно фильтровать, а кнопка на каждой модели открывает WhatsApp с готовым вопросом о цене и размерах.

## Структура

- `index.html` — содержание сайта и SVG-спрайт со стрелками, используемый через `<svg><use>`.
- `assets/css/site.css` — оформление и адаптация под телефон.
- `assets/js/site.js` — переключение языка, модальное окно каталога и карточки моделей.
- `data/catalog.js` — модели, категории, описания и опубликованные цены.
- `assets/images/` — логотип, переданные фотографии и временные концепт-визуализации.
- `assets/video/hero-room-sweep.mp4` — короткий вертикальный проезд по интерьеру из переданной фотографии для первого экрана.

## Просмотр

Откройте `index.html` в браузере. Для локального просмотра сборка и установка пакетов не нужны. Google Fonts подключается при наличии интернета; если его нет, сайт использует системный шрифт.

Цены и позиции каталога находятся в `data/catalog.js`. Нажатие на карточку категории открывает модальное окно только с моделями выбранной категории. Для модели без подтверждённой цены отображается «Цена по запросу».

Вместо галереи работ добавлен блок с этапами заказа: замер, согласование проекта и стоимости, изготовление, доставка и установка.

После блока «О нас» добавлен циклический слайдер отзывов с фото- и видеоформатами без рейтинга. Сейчас в нём стоят временные медиа и явно помеченные текстовые заглушки; перед публикацией их нужно заменить реальными материалами клиентов.
